# Audit notes
#
# * Dropped from the previous file (not imported anywhere in the tree):
#   sentencepiece, protobuf, ninja, einops. `ninja` is only needed if you build
#   the nunchaku kernel, which has its own instructions above.
#
# * gemlite is imported only by vendor/dualscale_kernel_benchmark/, inside a
#   try/except, and is not required by anything this repo runs.
#
# * quarot/vendor/rotation_utils.py imports `quant_utils` and `monkeypatch`,
#   which are modules from the upstream QuaRot repo that were never vendored
#   here. That code path is therefore broken independently of packaging --
#   it was already broken before this repo was extracted.
#
# * legacy_vendor/datautils.py calls load_dataset('wikitext', ...). Namespace-
#   less dataset ids are rejected by huggingface-hub >= 1.0; use
#   'Salesforce/wikitext' (already present as a commented-out line there) if you
#   hit `HfUriError`.
